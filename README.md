## 付款后必做的三件事：重置密码、远程连接、放行端口

新买的服务器先在控制台重置实例密码（必须重启才生效），再用SSH工具远程连接，最后在安全组里开放80、443等服务端口，三步做完才能正常对外使用。

1. 重置密码：进入ECS控制台的实例列表，找到刚买的服务器，点操作栏的“重置密码”。密码要求8-30个字符，大写字母、小写字母、数字、特殊字符四类里至少包含三类。提交之后**必须点一次“重启”，新密码才会生效**——这是新手最常见的坑，改完密码直接去登录，登不上还以为服务器出了问题。
2. 远程连接：以Xshell为例，新建会话，协议选SSH，主机填服务器的公网IP，端口默认22。连接后输入用户名（未创建自定义用户时默认是root，Windows是administrator）和刚重置的密码，登录成功就能通过命令行操作服务器。
3. 配置安全组：在实例列表点“更多”→“网络和安全”→“安全组配置”，进入目标安全组的“配置规则”，点“快速创建规则”：方向选“入方向”，授权策略“允许”，协议端口按服务填——网站是HTTP 80和HTTPS 443，SSH是22，数据库是3306；授权对象填0.0.0.0/0表示允许所有地址访问，有顾虑可以只填自己的IP段；优先级保持默认1。确定后重启服务器使规则生效。如果搭了服务还是打不开网页，再检查系统内部防火墙，比如Linux可以执行 systemctl stop firewalld 排查是不是本地防火墙拦的。

## 常见问题

**买的时候没勾公网IP，现在想要怎么办？**
绑定一个弹性公网EIP就行，不用重新买服务器。阿里云分配的公网IP是独享的。

**镜像选错了能换吗？**
能，操作系统镜像后续可以免费更换，购买时不用过度纠结。

**磁盘、带宽以后不够用怎么办？**
数据盘可以在创建后随时挂载；CPU内存、公网带宽和存储都支持弹性升降配，先按当前需求买，不够再加。

**重置密码后为什么还是登不上？**
大概率是没有重启实例。密码要重启之后才生效，重启一次再试。
